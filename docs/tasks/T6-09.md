## Quyết định đã chốt

- Theo ủy quyền làm tiếp/tự review, cùng nhánh wave/T6-4; không thêm dependency.
- RequestStore(config): save(prediction, image_mime, image) -> UUID string mới, get(job_id) -> StoredRequest|None,
  list_requests(limit=50, offset=0, status=None) -> list RequestSummary.
- Mỗi save là job riêng, receipt_id có thể lặp; chỉ nhận runner Prediction có decision review, ID rNNNN.
  Giữ raw receipt schema-invalid/null, metadata, Unicode; strict JSON/UTF-8 snapshot, không override reserved keys.
- Chỉ ảnh bytes 1..10MiB, MIME JPEG/PNG canonical; codec được API kiểm trước. SQL parameterized, mỗi op transaction riêng.
- StoredRequest chứa summary + MIME/bytes/prediction/correction; image và JSON không nằm trong repr.
  Summary gồm job_id/receipt_id/status/revision/created_at/updated_at, không ảnh hoặc prediction.
- List thứ tự created_at DESC/job_id DESC, limit1..100 và offset>=0, status review|corrected hoặc None.
- Không sửa/xóa request gốc hoặc promote dataset. Chưa có HTTP/policy/correction writer trong task này.
- Test DB thật chỉ database vireceipt_test; cleanup đúng UUID do test tạo, không reset bảng hoặc đọc test labels.
