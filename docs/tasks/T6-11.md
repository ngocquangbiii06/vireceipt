## Quyết định đã chốt

- GET /v1/requests: list metadata, limit mặc định50/max100, offset>=0, status review|corrected tùy chọn;
  response {items, limit, offset}, thứ tự repository; không tải bytes/JSON snapshot trong list.
- GET /v1/requests/{job_id}: summary + prediction/correction, không bytes; UUID sai422, thiếu404.
- GET /v1/requests/{job_id}/image: bytes gốc, MIME lưu trong DB; response Cache-Control: no-store.
- Route sync chạy thread pool; khi store chưa cấu hình trả503 storage_not_configured;
  lỗi repository trả503 storage_unavailable, không lộ credential/nội dung exception.
- Datetime ISO qua FastAPI encoder; JSON raw/null/Unicode và original prediction giữ nguyên.
- Test DB thật + synthetic/today cố định và lỗi với store giả; không dữ liệu thật, không dependency mới.
- Đây là API local chưa auth, chỉ hướng dẫn bind loopback; auth/public deploy để task riêng.
