## Quyết định đã chốt

- Chủ repo ủy quyền làm tiếp/tự review. PostgreSQL là thành phần roadmap, không thay bằng SQLite.
- Driver pg8000 BSD-3-Clause, group storage optional, ghim cận trên major; không thêm core dependency.
- DatabaseConfig.from_url nhận postgresql:// URL, validate host/port/database/user, credentials không ở repr/log.
  Loopback có thể không TLS; remote phải TLS xác minh chứng chỉ. Không nhận DSN từ HTTP request.
- Context connection commit khi thành công, rollback khi lỗi, luôn close; không chia connection giữa thread.
- init_database chạy SQL migration idempotent, không DROP/TRUNCATE dữ liệu hoặc tự reset DB.
- Table requests: UUID job_id, receipt_id rNNNN, image MIME/bytes, prediction JSON, correction JSON nullable,
  status review|corrected, revision số nguyên, created_at/updated_at; ảnh tối đa 10 MiB.
- Dùng JSON (không JSONB) cho prediction/correction để giữ raw JSON hợp lệ có escape U+0000;
  không tự validate/correct receipt ở DB. App sẽ kiểm trước khi ghi.
- Test unit config/transaction và DB thật trên cluster test riêng; không đọc labels/test.
- Môi trường chưa có Docker/Postgres native. Có thể tải/extract package Postgres 16 vào cache user WSL,
  chạy cluster tạm để test, không cài service hay sửa cluster/dữ liệu khác. Ghi rõ runtime/giấy phép/log.
