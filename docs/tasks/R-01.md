## Mục tiêu

Hiện CI chỉ `uv sync --locked` (không cài nhóm `api`, `storage`, `label`), nên các test dùng
`pytest.importorskip` bị **bỏ qua im lặng**, và 16 test PostgreSQL bị skip vì thiếu
`VIRECEIPT_TEST_DATABASE_URL`. Sau task này, mọi test đó chạy thật trên GitHub Actions.

## Bối cảnh cần đọc

- `.reviews/stack-T6-7.md` — mục "Phải sửa".
- `.github/workflows/ci.yml`
- `tests/conftest.py` (fixture `api_repository`), `tests/test_database.py` — test đòi database tên
  `vireceipt_test`.

- `.github/workflows/ci.yml`

- `docs/tasks/R-01.md`, `docs/tasks/README.md` (dòng R-01), bàn giao trong `docs/handoffs/`

Mọi file khác: không sửa. Cần sửa thì dừng task này và hỏi trong bàn giao.

## Quyết định đã chốt

- Service `postgres:16`, database `vireceipt_test`, user/password chỉ dùng cho CI (ghi thẳng trong
  workflow, không phải bí mật thật), có health check. (2026-10-26, chủ repo)
- Cài `uv sync --locked --group api --group storage --group label`. **Không** cài nhóm `ocr`
  (paddlepaddle quá nặng cho CI); test OCR vẫn được skip. (2026-10-26, chủ repo)
- Đặt `VIRECEIPT_TEST_DATABASE_URL=postgresql://<user>:<pass>@localhost:5432/vireceipt_test` cho bước
  pytest. (2026-10-26, chủ repo)
- Chạy pytest với `-rs` để log CI liệt kê lý do skip.
- Thêm trigger `push` cho nhánh `wave/**` để push nhánh đợt là CI chạy (không cần mở PR).
- Không thể chạy PostgreSQL trên máy chủ repo (không có Docker): kiểm cú pháp workflow bằng cách đọc
  lại; kết quả thật xem trên GitHub sau khi push. Ghi rõ điều này trong bàn giao, **không** ghi là
  "đã qua CI" khi chưa thấy.

## Các bước

1. Sửa `ci.yml` theo các quyết định trên.
2. Chạy cục bộ `uv sync --locked --group api --group storage --group label` rồi `uv run pytest -rs`
   để chắc không có lỗi import; ghi danh sách skip còn lại vào bàn giao.
3. Thêm đoạn README.
