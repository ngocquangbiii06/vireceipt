- App riêng streamlit run .../api_review_app.py -- --api http://127.0.0.1:8000,
  dùng group label và ReviewAPIClient; API/DB chạy riêng. Không thay app review file.
- Trang20 job, lọc all/review/corrected; chọn UUID (receipt ID có thể trùng), ảnh EXIF preview,

- Metadata store/source/quality bắt buộc chọn; reload correction đã lưu, giữ notes/Unicode.

  409 giữ draft, yêu cầu đối chiếu và bấm Đọc lại bản mới trước khi sửa tiếp.
- Reload/success thay editor generation để widget dùng giá trị server mới; UUID khác có state riêng.
- Báo Verification, không tự accept/promote, không đọc filesystem dataset hoặc chọn model.
- Kiểm bằng streamlit.testing.v1.AppTest trên Uvicorn + PostgreSQL thật với dữ liệu tổng hợp;
  không cần bấm browser thật, ghi rõ trong handoff. today cố định trong API test.
