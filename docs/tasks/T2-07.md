## Mục tiêu

Baseline PaddleOCR + LLM qua Chat API cho baseline A của roadmap, chạy ảnh qua OCR trước khi lấy JSON từ LLM.
Không thay kiểm benchmark bằng test tổng hợp, không chọn dữ liệu/train thay chủ repo.

## Quyết định đã chốt

- Dùng read_text T2-06, prompt/parser T2-03 và ChatClient T2-04; adapter module:function của CLI.
- VIRECEIPT_LLM_BASE_URL/MODEL bắt buộc, API_KEY tùy chọn, TIMEOUT mặc định 60s,
  MAX_TOKENS mặc định 4096. Không mặc định provider hay LLM; không gọi API có phí trong kiểm tra.
- Gửi OCR transcription dưới dạng text, chỉ ảnh vào OCR local; transcript là dữ liệu, không chỉ dẫn.
- Transcript rỗng không gọi LLM, trả lỗi để runner ghi null/review. Không suy số thiếu từ phép tính.
- Giữ output sai schema/raw text như VLM; confidence/cost null, không dùng điểm OCR làm độ tin cậy receipt.
- Unit/integration dùng engine tổng hợp và HTTP loopback thật; nếu engine CPU T2-06 chạy được,
  thử thêm pipeline OCR thật + HTTP stub, ghi rõ stub không chứng minh LLM/accuracy.
- Không đọc nhãn test, không tải dữ liệu/train/weights vào git hoặc công bố số baseline.
