## Mục tiêu

Khi có nhãn thật, đổi ngay được `train.jsonl` / `val.jsonl` thành file hội thoại cho fine-tune VLM,
dùng **cùng prompt** với backend VLM để train và suy luận khớp nhau. Chưa tải model, chưa train.

## Quyết định đã chốt

- Mỗi dòng ra: `{"id", "prompt_version", "image": "<đường dẫn tương đối>", "messages": [system,
  user(ảnh), assistant]}`; system = `build_prompt()`; user = một phần `image` trỏ tới file; assistant =
  JSON nhãn dump `sort_keys=True, ensure_ascii=False, separators=(",", ":")`. Không nhúng base64.
- **Từ chối** mọi đường dẫn nhãn có tên `test.jsonl` (cả đầu vào lẫn đầu ra), thoát mã 1.
- Ảnh thiếu → lỗi `image_missing` thoát 1 (không bỏ qua im lặng); `--skip-missing` thì bỏ qua và in
  số lượng bỏ qua.
- Ghi file ra kiểu nguyên tử (file tạm rồi `os.replace`), UTF-8, thứ tự giữ như file nhãn.
- Không thêm thư viện nào.

## Các bước

1. Hàm thuần `to_example(record, image_rel) -> dict`.
2. `main`: `vireceipt-sft-data <labels.jsonl> --images-root data --out <file.jsonl> [--skip-missing]`.
3. Test trên `tests/fixtures/gold.jsonl` với ảnh giả tạo trong `tmp_path`.
