## Mục tiêu

Gán nhãn 150 hóa đơn bằng cách gõ tay vào JSONL rất chậm và dễ sai. App hiện ảnh bên trái, form bên
phải theo đúng `docs/labeling-guide.md`; bấm lưu thì kiểm tra schema, hiện cảnh báo nhất quán, rồi ghi
vào `data/labels/all.jsonl`. **Logic tách khỏi giao diện** để test được.

## Các bước

1. `form.py` (không import streamlit):
   - `parse_date(text) -> str | None`: `12/11/2026`, `12/11/26`, `12-11-2026`, `2026-11-12` →
     `2026-11-12`; chuỗi rỗng → `None`; sai → `ValueError` có thông báo tiếng Việt.
   - `parse_time(text) -> str | None`: `18:42`, `18:42:10`, `6:42 PM`, `06:42 pm` → `18:42`.
   - `build_record(values: dict) -> dict`: từ giá trị form (chuỗi người dùng gõ) dựng một dòng nhãn
     đầy đủ theo guide mục 1; tiền dùng `parse_money`; chuỗi rỗng → `None`; `currency = "VND"`,
     `schema_version = "1.0"`. Trả về record; lỗi schema → `ValueError` liệt kê lỗi.
   - `next_id(existing_ids) -> str`: `r0001`, `r0002`, …
   - `unlabeled_images(images_dir, labels_path) -> list[Path]`: ảnh `.jpg/.jpeg/.png` chưa có trong nhãn.
   - `upsert_record(labels_path, record)`: thêm mới, hoặc thay dòng cùng `id`; ghi ra file tạm rồi
     `os.replace` để không hỏng file khi lỗi giữa chừng; giữ thứ tự các dòng khác.
2. `app.py`: `uv run --group label streamlit run src/vireceipt/labeling/app.py -- --data data`
   - Chọn ảnh chưa gán nhãn (hoặc chọn `id` có sẵn để sửa); hiện ảnh, có nút xoay 90°.
   - Form theo đúng thứ tự guide; `store_id` gợi ý từ các `store_id` đã có; `quality` chọn nhiều;
     bảng dòng hàng dùng `st.data_editor`.
   - Lưu: gọi `build_record` → `check_receipt` → hiện cảnh báo (vẫn cho lưu) → `upsert_record`.
   - **Chỉ đọc/ghi `data/labels/all.jsonl`.** Không bao giờ mở `train/val/test.jsonl`.
