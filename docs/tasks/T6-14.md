## Quyết định đã chốt

- ReviewAPIClient(base_url): list_requests(limit=20,offset=0,status=None), get(job_id), image(job_id),
  correct(job_id,body); UUID canonical, query urlencode. JSON trả dict, image bytes.
- Chỉ HTTP/HTTPS loopback (localhost hoặc IP loopback), không credentials/path/query/fragment/whitespace;
  API chưa auth nên scope local. Không env proxy, redirect hoặc retry, timeout10s.
- Giới hạn response JSON16MiB/ảnh10MiB; JSON UTF-8 strict/nonfinite/surrogate sai báo lỗi chung.
- ReviewClientError có status HTTP nếu có, thông báo chung không echo response/URL/input/secret;
  giữ409 để UI báo conflict. Không chọn model/provider hoặc thêm dependency.
- Test HTTP server stub loopback thật, dữ liệu tổng hợp, timeout/redirect/error/bounds/roundtrip.

## Tiêu chí xong
