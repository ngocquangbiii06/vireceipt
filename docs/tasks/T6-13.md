## Quyết định đã chốt

- PUT /v1/requests/{job_id}/correction: JSON receipt, expected_revision int strict>=0<=2147483646,
  store_id/source/quality bắt buộc, notes string mặc định ''; từ chối field lạ.
- Success200 {job_id, revision, verification}; status corrected nghĩa đã lưu bản sửa,
  không tự accept/promote dataset. Truyền today từ factory cho test cố định.
- 422 UUID/body/schema/metadata sai; 404 UUID thiếu; 409 revision_conflict yêu cầu đọc lại,
  không tự retry; 503 storage_not_configured/storage_unavailable chung, không lộ exception.
- Response no-store. Không sửa prediction/image, không gọi extractor khi PUT/GET correction.
- Validation error trả422 invalid_request chung, không echo input NaN/Infinity/surrogate gây lỗi JSON.
- Body JSON qua validation FastAPI; API vẫn local/loopback chưa auth, không triển khai public.
- Test DB thật synthetic, regression cho conflict/original snapshot/Unicode và số in sai;
  tự review cả wave, không dependency mới.
